# crate into the copy's tree; the direct crate's layout test (clang's record layouts compared with the fields the

#   python3 -I tools/plants/run-plants.py tools/api-crate-generator/plants.txt --workers 2
# with WCONTAINERS_MESA (Mesa's Meson build folder, its source beside it), WCONTAINERS_SPIRV_TOOLS and WCONTAINERS_CLANG.
