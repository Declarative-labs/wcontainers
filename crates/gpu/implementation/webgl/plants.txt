# The WebGL 2 back end's committed plant list for the text cargo-mutants never mutates: the GLSL strings of
# depth.rs on the paths the 24-bit depth work added (`unorm24` and the two conversions it checks against, the
# depth read's value, the comparison pass) and the Rust arguments that feed the comparison pass, one plant per
# operator and constant. Every plant keeps the GLSL valid, so it compiles and links; each must make a test fail.
# Run from the repository's root inside its `nix develop`, with an EGL library named (WCONTAINERS_EGL_FOLDER,
# EGL_PLATFORM=surfaceless, LD_LIBRARY_PATH) as the crate's tests need:
#   python3 -I tools/plants/run-plants.py crates/gpu/implementation/webgl/plants.txt --workers 3
# Not planted (said, not silent): the stencil programs, the cube direction (TOWARDS), the edge and bias
# probes' programs and the full-screen triangle, none of them the 24-bit depth work.
# No plant changes how unorm24 takes the whole part of d (2^24 - 1): for every word under both conversions
# the product rounds to a whole number (depth.rs's tests run all 2^24; truncating, rounding and
# taking the ceiling were each planted on 2026-11-27 and gave the same words), so the choice is no operator.
