# Status: engine-wasmtime

The WebAssembly engine interface (crates/webassembly-engine) implemented on wasmtime.
Crate: crates/webassembly-engine/implementation/wasmtime, package wcontainers-webassembly-engine-wasmtime.

## Plan (milestone E1)

- Built on wasmtime 50.0.1, the version and features crates/executor/implementation/wasmtime uses, with the
  proposals the translated modules need switched on: tail calls, typed function references, GC (which
  function references and exceptions need), exception handling, threads and shared memory, 64-bit memories,
  multiple memories.
- `Config`: the shared `wasmtime::Engine` (Clone). `Default` builds one with those proposals on. It also holds,
  made once on first use, the two small modules the shared-memory route below instantiates.
- `WasmtimeEngine<HostContext>`: one per thread; holds the config and a `wasmtime::Store<HostContext>`, so a
  host function gets `&mut HostContext` from wasmtime's own `Caller::data_mut`.
- Addresses are wasmtime's handles: `Func`, `Table`, `Global`, `Tag`, `Module`, `Instance`, `SharedMemory`.
  `MemoryAddress` is our type over a `Memory` or a shared memory (see below): one match per access.
- `FunctionTypeBinder<(A1..An), R>` is generated by one macro for every arity wasmtime's typed calls support
  (0 to 17), each over `Ai: WasmTy` and `R: WasmResults + WasmRet`: `bind_engine_function` is `Func::typed`,
  invoke is `TypedFunc::call`, `bind_host_function` is `Func::wrap` of a closure that spreads the arguments
  into the tuple. No dynamic values, no box or lock of ours.
- Errors: a trap is `wasmtime::Error`; an exception that leaves the call is recognised by wasmtime's
  `ThrownException`, taken out of the store, and answered `InvokeError::Exception`.
- Memory: an unshared memory reads and writes through `Memory::read`/`write`. wasmtime gives no safe access to
  the bytes of a `SharedMemory` (`SharedMemory::data` returns `&[UnsafeCell<u8>]`; its own documentation says
  that casting to atomics "must currently be done unsafely"). The safe route: for each shared memory in an
  engine, a helper instance that imports it and defines an unshared scratch memory, and exports `load` and
  `store`, which run `memory.copy` between the two; the host then reads or writes the scratch memory safely.
- Not shaped by one program; no engine-specific fast path now.
- Checks: the interface's suite (`tests!`), run as the crate's conformance test on the rented ARM64 machine.
  Extra tests in the crate for what the suite does not try (threads sharing a module and a shared memory,
  a host function trap path, an uncaught exception, every arity).
- Benchmark: `benches/engine.rs`, written against the interface's traits alone so other engines can run it.
